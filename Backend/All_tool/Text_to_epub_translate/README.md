# Text to EPUB Translate

Ứng dụng chuyển đổi văn bản và dịch thuật sang định dạng sách điện tử EPUB.

## Tính năng chính
- Trích xuất và xử lý văn bản tự động.
- Làm sạch tiêu đề, phân chia chương thông minh.
- Dịch thuật và hỗ trợ đa định dạng xuất.
- Kiểm tra tính hợp lệ của file EPUB với EPUBCheck.
- Giao diện Web trực quan.

## Cài đặt & Chạy ứng dụng

### 1. Cài đặt thư viện:
```bash
pip install -r requirements.txt
```

### 2. Khởi chạy ứng dụng Web:
```bash
python app.py
```
